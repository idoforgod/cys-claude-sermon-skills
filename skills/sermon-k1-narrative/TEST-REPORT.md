## 관찰

- **비차별 항목**: 수미쌍관·원포인트·전환 절·감정 곡선·귀납적 도입은 유명 이야기 본문(1·2·4)에서 미적용도 대체로 구현했다. K1 스타일을 프롬프트로 충분히 서술하면 베이스 모델도 상당 부분 해낸다.
- **차별 항목(스킬의 실효 가치)**:
  1. **일관성** — 미적용 통과율 편차(±15%)가 스킬 적용에서 사라진다(±0%). 설교자가 K1을 말로 다 풀지 못해도 매번 같은 품질.
  2. **부적합 본문 방어** (케이스 3) — 격차 최대. 억지 플롯 대신 라우팅.
  3. **방법론 충실도** (케이스 4) — 임도균 10단계·5렌즈의 명명·순서를 그대로.
  4. 형식 표준화 — 헤더, 전환문/반전/예화 표시, 전달 노트, 하나님-주어 중심 메시지.

- references 분량 대비 효과 재점검(토큰 비용). 현재는 4종 모두 산출에 활용됨.
- 부적합 본문 시 "산출 전 사용자 확인"을 더 강하게 할지 vs 현행("설명 + 대안 안내 + 라벨된 하이브리드 산출")을 유지할지 — 현행이 사용자 편의상 낫다고 판단해 유지.
